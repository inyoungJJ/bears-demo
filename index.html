Why BEARS

Key Features

What makes BEARS different from traditional electrode modeling workflows.

1

Fully Automated

From a single SEM image to electrochemical simulation results. No manual file conversion, no hand-tuning parameters between steps.

2

Real 3D Geometry

Uses actual particle shapes reconstructed from SEM, not idealized spheres. Captures morphological effects on transport and mechanics.

3

Multi-Agent AI

5 specialized agents collaborate through natural language. Each agent handles its domain autonomously, coordinated by an LLM orchestrator.

4

Extensible Skills

40+ modular skills that can be combined, versioned, and debugged independently. Add new capabilities without touching existing code.

5

8-Metric Validation

Every generated electrode is automatically validated against porosity, tortuosity, PSD, surface area, connectivity, and more.

6

Researcher-Friendly

Input parameters in familiar units (mg/cm2, AM:CB:Binder ratio). BEARS converts to simulation parameters automatically.

Workflow

Complete Pipeline in Detail

A closer look at what happens at each stage of the automated pipeline.

1

Parameter Collection

Researcher inputs loading (mg/cm2), thickness, composition ratio, and active material type. Optionally, a reference paper (PDF) can be provided for automatic parameter extraction.

2

Image Analysis & 3D Reconstruction

SEM images are segmented into individual particle masks. Each particle is reconstructed into a 3D mesh, then repaired and optimized for FEM compatibility.

3

Electrode Structure Generation

Particles are packed into a container using packing algorithms with collision detection. Supports polydisperse size distributions and multiple particle shapes.

4

3D Visualization & Compaction

The electrode is rendered in 3D and a physics-based compaction step densifies the structure. Geometry is exported in standard formats for downstream tools.

5

Structural Validation

8 metrics are computed: porosity (analytical + voxel), tortuosity, particle size distribution, surface area, connectivity, two-point correlation, and mesh quality.

6

Electrochemical Simulation

Geometry is imported into COMSOL. Materials, physics, and mesh are configured automatically. The solver runs and post-processes voltage curves, concentration fields, and stress maps.

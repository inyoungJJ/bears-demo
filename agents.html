Agents & Skills

5 specialized agents orchestrate 40+ skills to automate the entire electrode modeling pipeline.

What is an Agent?

An autonomous AI module that owns a specific domain. Agents plan which skills to use, handle errors, and complete multi-step tasks end-to-end without human intervention.

Like a domain expert who decides what tools to use and in what order, adapting when things go wrong.

What is a Skill?

A deterministic, reusable unit of work with defined inputs and outputs. Each skill does one thing well and produces reproducible results every time.

Like a specialized tool in a workshop — a drill always drills, a saw always cuts. The expert (agent) decides when to use each.

Agent = System Prompt + Equipped Skills + MCP Servers, running on a virtual machine with full tool access.

Skills load progressively into the context window — triggered on demand, not all at once.
